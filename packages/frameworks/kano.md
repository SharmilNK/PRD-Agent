# Kano Model — "Which features delight?"

**Creator:** Professor Noriaki Kano (1984).
**Used by:** Scorer (value, wow factor).

| Type | Meaning | Example (newsletter) |
|---|---|---|
| **Must-be (basic)** | Expected; missing it makes users angry | Technically correct explanations |
| **Performance** | More is better | More concepts covered per month |
| **Attractive (delighter)** | Unexpected; creates a "wow" | Concept-as-character stories + tiered quizzes |
| **Indifferent** | Users don't care | — |
| **Reverse** | Some users dislike it | Too much drama for experts who want speed |

A product needs all must-bes plus at least one clear delighter to score high on **Wow factor**.
