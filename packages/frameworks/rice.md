# RICE — "In what order do we build features?"

**Creator:** Intercom (Sean McBride). Common prioritization method.
**Used by:** Scorer (feasibility) and PRD Writer (requirement priority).

**Score = (Reach × Impact × Confidence) ÷ Effort**

| Part | Meaning | Typical scale |
|---|---|---|
| **Reach** | How many users does it affect in a time period? | number of users / quarter |
| **Impact** | How much does it help each user? | 3 = massive, 2 = high, 1 = medium, 0.5 = low, 0.25 = minimal |
| **Confidence** | How sure are we about the estimates? | 100% / 80% / 50% |
| **Effort** | How much work? | person-months |

Pair with **MoSCoW** (Must / Should / Could / Won't) for a simple label.
