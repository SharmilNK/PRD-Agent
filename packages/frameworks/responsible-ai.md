# Responsible AI frameworks — "Is it fair, safe, honest and private?"

**Used by:** Scorer (ethics), Standards agent, PRD Writer (Responsible AI, Explainable AI, Security sections).

| Framework | Owner | What we take from it |
|---|---|---|
| **Responsible AI Standard (v2)** | Microsoft | Six principles: Fairness, Reliability & Safety, Privacy & Security, Inclusiveness, Transparency, Accountability; Impact Assessment template |
| **People + AI Guidebook (PAIR)** | Google | "Does this need AI?", user trust, explainability, feedback, graceful failure |
| **AI Risk Management Framework (AI RMF 1.0)** | NIST (US) | Four functions: Govern, Map, Measure, Manage |
| **EU AI Act** | European Union | Risk levels (unacceptable / high / limited / minimal) and transparency duties (e.g., tell users content is AI-generated) |
| **OWASP Top 10 for LLM Applications** | OWASP | Prompt injection, sensitive data leaks, insecure output handling, excessive agency, etc. |
| **Model Cards** | Google (Mitchell et al., 2019) | Document intended use, limits, evaluation results |
| **ISO/IEC 42001** | ISO | AI management system standard (for later, when a company scales) |

**AI-fit check (from PAIR):** if a simple rule, template or search would do the job as well, AI is not needed — score AI-fit low.
