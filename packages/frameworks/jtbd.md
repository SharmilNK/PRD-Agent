# Jobs-to-be-Done (JTBD) — "What job is the user hiring this for?"

**Origin:** Clayton Christensen (Harvard), Tony Ulwick (Outcome-Driven Innovation).
**Used by:** Scorer (customer need) and PRD Writer (personas).

**Job statement format:** *When [situation], I want to [motivation], so I can [expected outcome].*

Check three layers of a job:
- **Functional** — the practical task (e.g., "refresh my memory on RAG before an interview")
- **Emotional** — how they want to feel (e.g., "confident, not overwhelmed")
- **Social** — how they want to be seen (e.g., "look knowledgeable to my team")

A strong customer need is **frequent**, **painful**, and **poorly served today**.
