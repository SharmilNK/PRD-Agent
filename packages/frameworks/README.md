# Frameworks

Product-management frameworks the agents use. **Every score must name a framework from here and give evidence.**

How they fit together:

| Question | Framework |
|---|---|
| Should we build this? (strategy) | [GUCCI](gucci.md) |
| What exactly should we build? (design) | [CIRCLES](circles.md), [JTBD](jtbd.md) |
| Can it succeed? | [Cagan's Four Risks](cagan-four-risks.md) |
| In what order? | [RICE](rice.md) |
| What delights? | [Kano](kano.md) |
| What value? | [Value Proposition Canvas](value-proposition-canvas.md) |
| How tough is the market? | [Porter's Five Forces](porter-five-forces.md) |
| Can it make money? | [Lean Canvas, TAM/SAM/SOM, AARRR](lean-canvas.md) |
| How do we measure UX? | [Google HEART](heart.md) |
| Can others copy it? | [7 Powers](seven-powers.md) |
| Is it responsible? | [Responsible AI frameworks](responsible-ai.md) |

The machine-readable rubric is [`scorecard.json`](scorecard.json). Agents load it to know which framework backs each score.
