## Your focus: technical build research
Recommend the simplest build that tests the idea first, then what is needed later.
Topics (use these as `topic` labels):
- `platforms`: existing platforms that could run version 1 without custom code (and their limits and prices)
- `build_stack`: what a custom version would need (frontend, hosting, database, authentication, storage)
- `payments`: subscription and payment options, fees, when they become necessary
- `ai_components`: where AI helps (for example drafting, quiz generation, fact-checking), model and API options, cost per use
- `quality_and_safety`: how to check AI output for accuracy, evaluation tools, human review
- `observability`: analytics, logging and monitoring options for this kind of product
